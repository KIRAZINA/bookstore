Bookstore API Tester

Interactive Swagger UI for local testing of the Bookstore API. Use the Authorize button to paste a JWT as a Bearer token, then send real requests directly to http://localhost:8080.

OpenAPI 3.1.0 Swagger UI via CDN JWT Bearer Auth Server: localhost:8080

Interactive Console

Controllers are grouped as Auth, Books, Cart, and Orders. Public auth endpoints stay open, while protected operations are preconfigured for Bearer token authorization.
